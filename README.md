# Magic Tape Echo

A CPU-conscious native stereo tape echo for Akai Force and MPC Gen1, with three playback heads, tape character, tempo sync, optional spring reverb and a slow, smooth VU meter.

![Magic Tape Echo](magic-tape-echo-three-heads.png)

## Downloads

Download the ARMv7 plugin package and matching source archive from the [Releases page](https://github.com/MagicStino/Magic-Tape-Echo/releases).

The plugin targets MPC OS 3.x on Force and MPC Gen1. No Gen2 build is provided. Full firmware 3.10 playback, MPC model and automation-screen Q-Link validation remain pending.
